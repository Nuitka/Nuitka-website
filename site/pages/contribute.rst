Help us make **Nuitka** even better. Whether you are a developer, a
writer, or an enthusiast, there is a way for you to contribute, and it
is very much appreciated.

****************************
 Support Nuitka Development
****************************

**Nuitka** is Free Software, largely developed by a single person in
their spare time. Your contribution directly funds the ongoing
development of the free version.

.. grid:: 1 1 2 2
   :gutter: 1
   :class-container: hub-card-set contribute-hub

   .. grid-item-card:: :doc:`/commercial/purchase`

       Subscribe to **Nuitka Commercial** and directly support ongoing
       development. Commercial revenue enables continuous improvements
       to the free version.

   .. grid-item-card:: :doc:`/pages/donations`

       Make a one-time or recurring donation to exclusively support free
       **Nuitka** development and help the project thrive.

*************************
 Community Contributions
*************************

You do not need to be a compiler engineer to make a real difference.

.. grid:: 1 1 2 2
   :gutter: 1
   :class-container: hub-card-set contribute-hub

   .. grid-item-card:: :doc:`/pages/website-manual`

       Help others succeed with **Nuitka** by improving the
       documentation and the website.

   .. grid-item-card:: :doc:`/user-documentation/nuitka-package-config`

       Add support for packages with missing DLLs or data files using
       **Nuitka Package Configuration**.

   .. grid-item-card:: Issue Triage

       Help assess, categorize, and solve community issues on the issue
       tracker. Join the `Issue Triage Team
       <https://discord.gg/nZ9hr9tUck>`_ on Discord.

**********************************
 Advanced Developer Contributions
**********************************

Ready to dive deeper? Join the core development effort itself.

.. grid:: 1 1 2 2
   :gutter: 1
   :class-container: hub-card-set contribute-hub

   .. grid-item-card:: :doc:`/user-documentation/nuitka-package-config`

       Help reduce bloat in standard packages. Target unnecessary
       package usages, reduce optional dependencies, and improve
       compilation speed and output size. See the problem described in
       :ref:`anti-bloat`.

   .. grid-item-card:: :doc:`/doc/developer-manual`

       Enhance **Nuitka**'s optimization capabilities. Python skills are
       essential, C skills helpful but not required. Start with the
       :doc:`Developer Manual </doc/developer-manual>`, explore the
       :doc:`API documentation </doc/api-doc>`, and join the `Discord
       server <https://discord.gg/nZ9hr9tUck>`_ to get involved.
