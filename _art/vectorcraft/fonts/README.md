# Wordmark font reference

The approved Nuitka wordmark is **Inter SemiBold 600**, effective **216 px** in the 1200×260 lockup,
with **−27/1000 em** kerning on the `u` (equivalent to −3 px at the 112 px comparison size) and
tracking 0.

The editable master uses VectorCraft’s built-in Inter. `Inter-Variable.ttf` and
`licenses/OFL-Inter.txt` are kept here as the exact reference file and license for the approved
typeface.

- `Inter-Variable.ttf` - Inter (Google Fonts)
- `licenses/OFL-Inter.txt` - SIL Open Font License 1.1

The earlier IBM Plex Sans, Space Grotesk, Source Sans 3, and NanumGothic comparison assets have been
removed now that the decision is closed. NanumGothic was the pre-Inter wordmark; it is not retained
in this branch and must not be used for new artwork.

License note: SIL OFL 1.1 permits commercial use, modification, embedding, and outlining. Keep the
license text if the font file itself is redistributed.
